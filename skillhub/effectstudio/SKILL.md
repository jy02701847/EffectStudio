# EffectStudio · 效果图洗图软件（Windows 绿色版）

针对建筑效果图/室内渲染图优化的本地调色软件：自动分析直方图并套用影调与色彩方案，
输出干净通透的成片，不偏色、不过曝。全部计算在本机完成，图片不上传。

## 包内容

- `EffectStudio_v1.1.0_绿色版.zip` —— 完整程序，解压即用

## 安装（部署即用）

1. 把本技能安装到本地后，找到 `EffectStudio_v1.1.0_绿色版.zip`
2. 解压到任意目录（如 `D:\EffectStudio`）
3. 双击 `EffectStudio.exe`，会自动弹出操作窗口
4. 把图片拖进窗口 → 点处理 → 完成后可单张保存或批量导出 ZIP

无需安装、无需管理员权限、无后台进程。

## 系统要求

- Windows 10/11（64 位）
- 纯调色功能：无显卡要求，1080p 约 2~3 秒，8K 约 20~35 秒
- 神经网络降噪（DLSS5 净化，可选）：需要 NVIDIA 显卡并另行安装 NeuralScreen 运行时，未安装时自动跳过，不影响其他功能

## 更新方式

以仓库发布为主：新版本在仓库/技能平台更新后，按相同步骤下载新的 zip 解压覆盖即可，
配置与产出图保留在程序目录旁不受影响。

## 使用提示

- 默认「智能 Auto」自动识图定参数；力度/质感/色温滑块可微调
- 处理结果默认保存在程序目录的 `output` 文件夹
